# P_Passion-lecture
Projet du Module 151 visant à réaliser une application sur la thématique des livres. Cette dernière doit avoir les options suivantes :
- Création de compte
- Ajout, modification et suppression de livres
- Ajout d'avis avec notation sur 5
- Affichage des livres par catégorie ou par une recherche

PHP, SQL et Tailwind CSS sont utilisés dans ce projet.  
La structure du site est en MVC.
